# charchika.sinha — portfolio

Next.js site. Content lives in `content/`:

- `site.ts` — name, tagline, email, links, résumé files
- `projects.ts` — projects (a project with `page` gets its own page)
- `career.ts` — career timeline and headline numbers
- `signals.ts` — Current Signal (newest first; its photo becomes the dot sculpture)
- `notes.ts` — notes stream

Images go in `public/`. Run locally with `npm install && npm run dev`.
